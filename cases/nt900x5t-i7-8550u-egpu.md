# 📱 [Case #01] 삼성 노트북9 올웨이즈 (i7-8550U) + GTX 1080 eGPU 발열 케어

> **환경**: Windows 11 | 초경량 15인치 노트북 | Thunderbolt 3 eGPU  
> **핵심 성과**: 
> * **CPU 온도**: 부하 시 최고 온도 **95°C ➡️ 53°C~65°C**로 30°C 이상 감축
> * **eGPU (GTX 1080) 온도**: **47°C ➡️ 41°C**로 감축 / 팬 소음 극저소음화

---

## 1. 📌 케이스 개요 및 증상

* **대상 기기**: 삼성 노트북9 Always 15" (`NT900X5T`)
* **사양**: Intel Core i7-8550U (4C/8T) + 16GB RAM + NVIDIA GeForce GTX 1080 eGPU (AORUS Gaming Box)
* **초기 증상**: 
  * 마우스 이동 및 가벼운 인터넷/유튜브 시에도 CPU 클럭이 4.0GHz로 순간 발작하며 온도가 **95°C**까지 폭발.
  * 열을 식히지 못해 **발열 쓰로틀링(Throttling)**으로 클럭이 1.5GHz 이하로 떡락하여 게임 프레임이 심하게 널뛰는 현상 발생.

---

## 2. 🔍 원인 분석

1. **초경량 폼팩터의 쿨링 해소 한계**: 히트파이프 및 팬 용량이 **18W ~ 22W** 수준인데, CPU 순정 터보 부스트가 **35W~40W**를 요청함.
2. **SpeedShift EPP 미적용 (`SpeedShift=0`)**: 인텔 HWP 컨트롤러가 꺼져 있어 윈도우 스케줄러의 미세 자극에도 무조건 최고 터보 클럭(40.00x)을 내어줌.
3. **PL2(순간 전력) 44W 해제**: TPL 제어가 안 되어 순간적인 전압/전력 튐으로 80~90°C 이상 온도가 급증함.
4. **eGPU 100% 풀 파워 소모**: 썬더볼트 3 대역폭(PCIe 3.0 x4) 한계가 있음에도 eGPU가 180W 풀파워를 쓰며 미니 하우징 팬 소음 유발.

---

## 3. 🛠️ 해법 및 세팅 가이드

### (1) CPU SpeedShift EPP `160` 설정 (부하 비례 조율)
* `Speed Shift - EPP` 수치를 **`160`**으로 설정.
* C0% 가동률 25~40% 상황에서 클럭을 3.1GHz로 쏘지 않고 **`1.68GHz ~ 2.54GHz`로 비례 조절**하여 온도를 50°C 대 유지.

### (2) CPU FIVR 스윗스팟 클럭 제한 (`31x` ~ `28x`)
* `Turbo Ratio Limits`를 **`31` (3.1GHz)** 또는 **`28` (2.8GHz)**로 상한선 봉인.
* 전력 소모가 35W ➡️ **11W~16W**로 감축되어 성능 손실 체감 없이 발열 완전 제거.

### (3) CPU TPL 전력 수문장 봉인
* `Long Power PL1`: **`19W` + Clamp 체크**
* `Short Power PL2`: **`22W` + Clamp 체크**
* `Turbo Time Limit`: **`32초`**

### (4) eGPU (AORUS GTX 1080 Gaming Box) 전력 타겟 80% 봉인
* **Power Target**: **`80%` (-20%)** ➡️ 최대 전력 한도 **144W (180W * 0.8)**로 봉인
* **효과**: 썬더볼트 대역폭 특성상 실 성능 감소는 2% 이내로 체감 불가하나, **eGPU 온도가 41°C로 극적인 저발열/무소음화 달성!**

---

## 💡 [하드웨어 알려진 이슈 & 트러블슈팅] AORUS Gaming Box 재연결 래치(Latch) 버그

* **증상**: 썬더볼트 케이블을 핫플러그(Hot-Unplug)로 뺐다가 다시 꽂았을 때, 윈도우 장치 관리자에서 `CM_PROB_PHANTOM` (유령/인식 안 됨) 오류가 나며 eGPU가 안 켜지는 현상.
* **원인**: AORUS 게이밍 박스 내장 450W Flex-ATX 파워서플라이 차단 회로가 신호 차단 시 대기 래치(Standby Latch) 상태로 잠겨버리기 때문.
* **해결법**: 
  1. 썬더볼트 케이블을 뺀 상태에서 **eGPU 220V 전원 코드(플러그)를 5초간 뽑아서 파워 회로를 완전 리셋**
  2. 220V 코드를 다시 꽂은 후 썬더볼트 케이블을 노트북에 꽂으면 1초 만에 정상 인식 복구!

## 4. 📊 최종 실측 검증 데이터 (Live Data)

```
[CPU 튜닝 전] 순정 상태 (4.0GHz / 35W)       ===>  온도 95°C (스로틀링 떡락)
[CPU 튜닝 후] EPP 160 + PL1 19W (2.5GHz)     ===>  온도 53°C ~ 65°C (전력 7.2W~13W, 차가움!)
[eGPU 튜닝 후] Power Target 80% (144W 봉인) ===>  eGPU 온도 41°C (Power Draw 35W, 완전 무소음!)
```
